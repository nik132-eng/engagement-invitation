# Nikunj & Ayushi – Engagement Invitation

Static site (no build step). Open `index.html` or deploy the folder to Vercel.

## Edit details
Everything editable is in `config.js`: time, venue name/address, map link,
WhatsApp RSVP number, background music, and gallery photos.

Add photos to an `assets/` folder and list them in `config.js`:
`photos: ["assets/photo1.jpg", "assets/photo2.jpg"]`

Text (names, parents, messages) in English and Gujarati is in `script.js`.
